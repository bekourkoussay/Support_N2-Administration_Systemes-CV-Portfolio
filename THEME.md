# DARK TECH NEXUS — Design System

## Direction artistique
Portfolio IT sombre, premium et responsive, inspiré des interfaces d'exploitation, réseaux et observabilité.

### Effets
- réseau de nœuds animé sur canvas ;
- connexions dynamiques entre nœuds ;
- halos colorés et gradients radiaux ;
- grille technique en arrière-plan ;
- scanline / balayage lumineux ;
- glow piloté par le curseur ;
- barre de progression de lecture ;
- bouton retour en haut ;
- micro-interactions sur les cartes et boutons.

## Accessibilité
- navigation clavier ;
- focus visible ;
- lien « Aller au contenu » ;
- boutons avec libellés ARIA ;
- contenu principal identifié ;
- responsive mobile ;
- prise en compte de `prefers-reduced-motion`.

## Thèmes par page
- Accueil : cyan / violet / vert
- Expérience : bleu / violet
- Compétences : turquoise / bleu
- Projets : violet / magenta / orange
- Labs : vert / cyan
- Sécurité : rouge / orange
- Contact : or / cyan

Aucune dépendance externe n'est requise pour le rendu visuel.
